# Tetris

Browser-based Tetris game built with HTML5 Canvas and JavaScript. Classic block puzzle with score tracking, level progression, hold piece, and next piece preview.

## Play Online
https://jazblue.github.io/tetris/

## How to Play
- **Arrow keys / A/D** — Move left/right
- **Arrow up / X** — Rotate clockwise
- **Arrow down / S** — Soft drop
- **Space** — Hard drop
- **C** — Hold piece
- **P** — Pause
- **R** — Restart

## Controls
| Key | Action |
|-----|--------|
| ← / A | Move left |
| → / D | Move right |
| ↑ / X | Rotate clockwise |
| ↓ / S | Soft drop |
| Space | Hard drop |
| C | Hold piece |
| P | Pause |
| R | Restart |

## Features
- Classic Tetesis gameplay with 7 shapes (I, O, T, S, Z, J, L)
- Score, best, lines, and level tracking
- Hold piece mechanic
- Next piece preview
- Responsive design (works mobile & desktop)
- Saves best score to localStorage
- Game over state with restart

## Tech Stack
- HTML5 Canvas
- Vanilla JavaScript (ES6+)
- CSS Grid/Flexbox for layout
- No dependencies — runs in any modern browser

## Local Development
1. Clone the repo
2. Open `index.html` in any web browser
3. No build step or dependencies required
